## 🚀 Features (What makes it Dynamic Cloud?)

#### 1. Dynamic Budget & Goal Planning
- Set Monthly Budget and Savings Goal (Bike, Laptop, Trip)
- Real-time progress bar that updates automatically
- Data persists in phone + cloud

#### 2. Cloud Expense Tracking
- Add expenses with Amount, Category, Note, Date
- **Instantly saves to Google Sheets Cloud Database** via Apps Script API
- Works offline - syncs when internet comes back

#### 3. Smart Analytics Dashboard
- Interactive Pie Chart (Category wise)
- Bar Chart (Monthly Spending)
- Total Spent, Remaining Budget, Savings Status
- Built with Chart.js

#### 4. Progressive Web App (PWA)
- Installable on Android / iPhone / PC like a real app
- Works offline with Service Worker (`sw.js`)
- Fast loading, no Play Store needed

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript (Vanilla) |
| **PWA** | `manifest.json`, `sw.js` (Service Worker) |
| **Charts** | Chart.js |
| **Cloud Database** | Google Sheets + Google Apps Script (REST API) |
| **Hosting** | GitHub Pages (Free Cloud Hosting) |
| **Storage** | LocalStorage (Offline) + Cloud Sync |
